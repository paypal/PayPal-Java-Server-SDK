
# Vault Customer

This object represents a merchant’s customer, allowing them to store contact details, and track all payments associated with the same customer.

## Structure

`VaultCustomer`

## Fields

| Name | Type | Tags | Description | Getter | Setter |
|  --- | --- | --- | --- | --- | --- |
| `Id` | `String` | Optional | The unique ID for a customer generated by PayPal.<br><br>**Constraints**: *Minimum Length*: `1`, *Maximum Length*: `22`, *Pattern*: `^[0-9a-zA-Z_-]+$` | String getId() | setId(String id) |
| `Name` | [`Name`](../../doc/models/name.md) | Optional | The name of the party. | Name getName() | setName(Name name) |

## Example

```java
import com.paypal.sdk.models.Name;
import com.paypal.sdk.models.VaultCustomer;

VaultCustomer vaultCustomer = new VaultCustomer.Builder()
    .id("id8")
    .name(new Name.Builder()
        .givenName("given_name2")
        .surname("surname8")
        .build())
    .build();
```
